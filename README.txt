STAYWELCOME PRO — COMPLETE DIGITAL PRODUCT
Version: 2.0
Product type: editable multilingual guest guide for vacation rentals and holiday homes.

FILES
- index.html: the standalone guest guide application.
- QUICK_START.pdf: host setup and publishing instructions.
- PRODUCT_LISTING.txt: suggested Etsy / independent-store listing copy.
- LICENSE.txt: personal-business end-user license.
- QUALITY_CHECKS.txt: compatibility and verification notes.

HOW TO USE
1. Extract the ZIP archive.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. Choose the language for the guest-facing guide.
4. Select “Edit guide”, replace all example content and enter the property details.
5. Select “Finish editing” to save in the current browser on the current device.
6. Use “Export backup” to download a JSON backup. Keep it in a safe place.
7. Use “Print / Save PDF” and select “Save as PDF” in the browser print dialog.
8. To share the digital guide, upload index.html to your own website or hosting service and share its public URL with confirmed guests.

IMPORTANT
- This is a self-contained HTML guide; it does not require an account or subscription.
- Browser-local saved data does not automatically sync between devices. Export and import a backup to move data.
- The guide does not host itself online. A public URL requires a hosting service. An optional QR code can be generated from that public HTTPS URL; the QR feature requires internet access and uses a third-party QR service.
- Do not publish Wi-Fi passwords, door codes, key-safe codes, personal data or emergency access details in a public listing. Share sensitive access details privately with confirmed guests.
- All example text is generic guidance, not legal or safety advice. The property host must verify local laws, emergency numbers, building rules, accessibility statements, addresses, opening hours and safety equipment.
- The interface is translated into English, Italian, German, French and Spanish. The host's own property content is entered by the host and is not automatically translated.
- “Print / Save PDF” prints the complete guide chapters. For best results choose A4, background graphics off or on as preferred, and check the preview before saving.
